# Tankzors Pro — Android

Готовый проект Android Studio. Внутри та же игра, что и на iPhone (`app/src/main/assets/web`): кампания из 37 миссий,
мастерская без SMS, сетевая игра на 2–4 игрока с ботами, гибридами и большими картами.
Нативная часть на Java: WebView, сохранения, вибрация, кнопка «Назад», геймпад, вырезы экрана, сетевая игра.

## Как получить APK

**Без установки чего-либо — GitHub Actions.** Создайте приватный репозиторий на GitHub и залейте в него содержимое
этой папки. Откройте Actions → **Android APK** → Run workflow (при push он запускается сам). Через 3–5 минут
в разделе Artifacts появится `TankzorsPro-apk` с файлом `app-release.apk`.

**Android Studio.** File → Open → эта папка, дождитесь синхронизации Gradle, затем Build → Build APK(s).
Или из терминала: `./gradlew assembleRelease`. Готовый файл: `app/build/outputs/apk/release/app-release.apk`.
Нужны JDK 17 и Android SDK 35 (Android Studio ставит их сама).

## Установка
Скопируйте APK на телефон и откройте его. Разрешите «Установка из неизвестных источников» для файлового
менеджера или браузера. Или через компьютер: `adb install -r app-release.apk`.

APK подписан ключом `app/tankzors.jks` (пароль `tankzors`). Храните этот файл: новые версии, подписанные им,
ставятся поверх старой и сохраняют прогресс. Минимальная версия Android — 7.0.

## Управление
- **Экран.** Работает и в вертикали, и в горизонтали, ориентация меняется на лету.
- **Кнопки.** Плавающий джойстик, огонь (удержание — очередь), припасы, задний ход, ремонт, радар, обзор.
  В горизонтали быстрые кнопки стоят рядом над огнём. Шестерёнка открывает настройки: язык, качество графики,
  звук, вибрацию, прозрачность и размер кнопок, режим левши, фиксированный джойстик.
- **Геймпад или клавиатура.** Крестовина/WASD — движение, A/Enter/Пробел — огонь, B/Start/Esc — меню,
  Select — оружие, X — снабжение, Y — ремонт, L1 — задний ход, R1 — радар.

## Сетевая игра
Кнопка «Сеть» в главном меню. Играть можно вдвоём, втроём или вчетвером. Телефоны должны быть в одной Wi‑Fi
сети или на точке доступа одного из них. Игра находит соседей сама, IP вводить не нужно. iPhone и Android играют
вместе: протокол один и тот же (Bonjour/NSD `_tankzors._tcp`, WebSocket на порту 47700).

Бой считает телефон создателя, поэтому его приложение должно оставаться открытым (экран сам не гаснет).
Если у кого-то пропал Wi‑Fi, игра не тормозит у остальных, а он сам переподключается в свой танк.
Чтобы сыграть следующий бой с теми же друзьями, создатель жмёт в паузе «Закончить бой — всех в комнату».
